so it will give us "n" and ask us minimum number we can add to this number to make it perfect.
for example 25 is 5x5 so 25 is already a perfect number and we have to print 0 for this test case.
a good aproch is we write a loop and continue until find a number that is perfect number.
we can check this with "n ** 0.5" in python and if it's int so it's a perfect number.
```python
for _ in range(int(input())):
    n = int(input())
    ans = 0
    while n ** 0.5 != int(n ** 0.5):
        n += 1
        ans += 1
    print(ans)
```
